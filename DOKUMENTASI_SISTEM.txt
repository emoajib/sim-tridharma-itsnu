================================================================================
                          SPESIFIKASI HOSTING & INFRASTRUKTUR
================================================================================

TIPE HOSTING: 
- Virtual Private Server (VPS) atau Cloud Server (WAJIB).
- TIDAK MENDUKUNG Shared Hosting / cPanel (karena butuh install pgvector & Python daemon).

HARDWARE MINIMUM (Minimum Requirements):
- CPU: 4 Cores (Dedicated atau High-Performance vCPU).
- RAM: 4 GB (Minimum mutlak untuk memuat model embedding AI).
- Storage: 40 GB SSD / NVMe (Untuk database PostgreSQL & data MinIO).
- Network: 100 Mbps bandwidth (Untuk akses API Gemini & sinkronisasi eksternal).

HARDWARE REKOMENDASI (Recommended for Production):
- CPU: 8 Cores.
- RAM: 8 GB - 16 GB (Untuk performa chatbot RAG yang lebih responsif).
- Storage: 80 GB SSD / NVMe.

================================================================================
                    SPESIFIKASI PC (LOCAL DEVELOPMENT - WINDOWS)
================================================================================

Agar sistem AI berjalan lancar di PC lokal (Windows), gunakan spesifikasi berikut:

HARDWARE MINIMUM:
- CPU: Intel Core i5 / AMD Ryzen 5 (Gen 10+).
- RAM: 16 GB (WAJIB: Karena WSL2 + Docker + Laravel + AI Services memakan banyak RAM).
- Storage: SSD (Wajib, minimal 50GB ruang kosong).

SOFTWARE ENVIRONMENT:
- Windows 10/11 Pro/Enterprise.
- WSL2 (Windows Subsystem for Linux) - WAJIB (Disarankan Ubuntu 22.04 di dalam WSL).
- Docker Desktop (Opsional, tapi disarankan untuk PostgreSQL & RabbitMQ).
- Node.js v20+ & PHP 8.4+ (Bisa via Laravel Herd atau manual di WSL).
- Python 3.11+ di dalam lingkungan WSL.

Catatan: Menjalankan sistem AI langsung di Windows native (tanpa WSL2) tidak disarankan karena kesulitan instalasi ekstensi PostgreSQL tertentu dan manajemen library Python.
